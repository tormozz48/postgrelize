## By task

| I want to...                                    | Use                                                                    | Where                                                                                                                                   |
| ----------------------------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Define a model                                  | `sequelize.define`, `class extends Model` + `init`, or decorators      | [Models](/guide/models), [Decorators](/guide/decorators)                                                                                |
| Store JSON, arrays, ranges, UUIDs, geometry     | `DataTypes.JSONB`, `ARRAY`, `RANGE`, `UUID`, geometric types           | [Models: data types](/guide/models#data-types)                                                                                          |
| Use an identity or generated column             | `identity`, `generated` attribute options <Ext />                      | [Identity and generated columns](/guide/models#identity-generated)                                                                      |
| Filter rows with operators                      | `where` with `Op`                                                      | [Filtering](/guide/querying#filtering)                                                                                                  |
| Search text (full-text, trigram, `SIMILAR TO`)  | `toTsQuery`, `tsRank`, `trigramSimilarity` <Ext />                     | [Operator and search helpers](/guide/querying#operator-and-search-helpers)                                                              |
| Paginate                                        | `limit`, `offset`; keyset with `tuple` <Ext />                         | [Paginating](/guide/querying#selecting-ordering-and-paginating), [Keyset](/guide/advanced-queries#row-comparison-and-keyset-pagination) |
| Count and aggregate                             | `count`, `sum`, `max`, `group`                                         | [Aggregates](/guide/querying#aggregates-and-expressions)                                                                                |
| Load related rows                               | `include`                                                              | [Eager loading](/guide/associations#eager-loading)                                                                                      |
| Take the latest N rows per parent               | `include` with `lateral` <Ext />                                       | [LATERAL joins](/guide/advanced-queries#lateral-joins-and-top-n-per-parent)                                                             |
| Reuse a filter                                  | scopes                                                                 | [Scopes](/guide/querying#scopes)                                                                                                        |
| Run raw SQL safely                              | `sequelize.query` with `replacements` or `bind`                        | [Raw SQL](/guide/querying#raw-sql)                                                                                                      |
| Lock rows                                       | `lock`, `skipLocked`, `noWait` <Ext />                                 | [Locking](/guide/querying#locking), [Row locks](/guide/transactions#row-locks)                                                          |
| Insert or update in one statement               | `upsert`, `onConflict` <Ext />                                         | [Upserts](/guide/upserts)                                                                                                               |
| Read old values after an update                 | `returningOld` <Ext /> (PostgreSQL 18)                                 | [RETURNING OLD](/guide/upserts#old-values-with-returningold-postgresql-18)                                                              |
| Insert many rows quickly                        | `bulkCreate` with `unnest` <Ext />, `copyFrom` <Ext />                 | [Bulk writes](/guide/bulk-writes)                                                                                                       |
| Update or delete using another table            | `updateStatement`, `deleteStatement` <Ext />                           | [UPDATE ... FROM](/guide/bulk-writes#update-from)                                                                                       |
| Sync rows from a source table                   | `Model.merge` <Ext />                                                  | [MERGE](/guide/bulk-writes#merge)                                                                                                       |
| Export a table                                  | `copyTo` <Ext />                                                       | [Export with `copyTo`](/guide/bulk-writes#export-with-copyto)                                                                           |
| Process a huge table in batches                 | `findEach` <Ext />                                                     | [`findEach`](/guide/advanced-queries#server-side-cursors-with-findeach)                                                                 |
| Write recursive or multi-step queries           | CTEs: `with`, `source` <Ext />                                         | [Common table expressions](/guide/advanced-queries#common-table-expressions)                                                            |
| Rank or number rows                             | `over(...)` window functions <Ext />                                   | [Window functions](/guide/advanced-queries#window-functions)                                                                            |
| Run several statements atomically               | `sequelize.transaction`                                                | [Transactions](/guide/transactions)                                                                                                     |
| Pick an isolation level or read-only mode       | `isolationLevel`, `readOnly`, `deferrable` <Ext />                     | [Transactions](/guide/transactions#read-only-transactions)                                                                              |
| Serialize work across processes                 | `withAdvisoryLock` <Ext />                                             | [Advisory locks](/guide/sessions#advisory-locks)                                                                                        |
| Push events between processes                   | `listen`, `notify` <Ext />                                             | [LISTEN / NOTIFY](/guide/sessions#listen-notify)                                                                                        |
| Send reads to replicas                          | `replication` <Ext />                                                  | [Read replicas](/guide/sessions#read-replicas)                                                                                          |
| Stop a slow query                               | `statementTimeout` <Ext />                                             | [Statement timeout](/guide/sessions#statement-timeout-per-query)                                                                        |
| Retry transient failures                        | `retry`                                                                | [Retrying](/guide/sessions#retrying-failed-queries)                                                                                     |
| Handle a unique or foreign key violation        | `UniqueConstraintError`, `ForeignKeyConstraintError`                   | [Errors](/guide/errors)                                                                                                                 |
| Validate input                                  | validators, `validationSchema` <Ext /> (zod, valibot)                  | [Hooks and validation](/guide/hooks-validation)                                                                                         |
| React to create / update / destroy              | hooks                                                                  | [Hooks](/guide/hooks-validation#hooks)                                                                                                  |
| Create tables, indexes and constraints          | `sync`, `QueryInterface.createTable`, `addIndex`                       | [Schema](/guide/schema), [Constraints and indexes](/guide/constraints-indexes)                                                          |
| Use views, sequences, triggers, partitions, RLS | `QueryInterface.createView`, `createPartition`, `createPolicy` <Ext /> | [Schema objects](/guide/schema-objects), [Partitioning](/guide/constraints-indexes#declarative-partitioning)                            |
| Tune pool size, logging, timezone               | `Sequelize` constructor options                                        | [Connection](/guide/connection)                                                                                                         |
| Move from Sequelize v6                          | change the import                                                      | [Migrating](/guide/migrating)                                                                                                           |
